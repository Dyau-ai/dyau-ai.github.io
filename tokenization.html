        Step 3 · Analytics without exposure
        
Find a customer and join tables using tokens alone — nothing gets detokenized

        
Deterministic tokens mean the same value always produces the same token under the same key, so equality search, joins and group-bys run directly on tokenized columns.

      


      

        

          

            
Look up a customer by ID

            WHERE id = tokenize(?)
          

          

            
            
          

          
Try:

          

        


        

          

            
Join transactions to customers

            ON customers.id_tok = transactions.id_tok
          

          
Both tables were tokenized independently at ingest. The join runs on tokens; the plaintext join is computed only to prove the counts match.

        Step 4 · Under the hood
        
Format rules, the NIST safety floor, card numbers and key rotation

        
Every field type has its own profile. Fields too short to encrypt safely are refused rather than silently weakened.

Minimum domain check

            radixlength ≥ 1,000,000
          

          
Small domains can be brute-forced or reconstructed whatever the key size, so NIST sets a floor of one million possible values.
